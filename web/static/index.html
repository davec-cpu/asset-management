Go embed + precompress

Trang này được serve từ một binary Go duy nhất. Toàn bộ HTML/CSS/JS đã được nén sẵn (gzip + brotli) lúc build và nhúng bằng go:embed.

Kiểm tra encoding thực tế

Bảng dưới do app.js điền, đọc từ Resource Timing API:

ResourceTransfer sizeDecoded sizeTiết kiệm

Mở DevTools → Network để thấy header Content-Encoding: br (hoặc gzip) và Vary: Accept-Encoding.
